# 🔥 Pluffy Bird: Infernal Blaze

A fast-paced, high-octane fire-themed arcade flight game built with vanilla HTML5 Canvas, responsive CSS, and procedural Web Audio API.

---

## 🎮 How to Play

Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari) or run:
```powershell
Start-Process "index.html"
```

### Controls

| Action | Keyboard | Mouse | Touch / Mobile |
| :--- | :--- | :--- | :--- |
| **Flap Wings** | <kbd>Space</kbd> / <kbd>▲ Up</kbd> / <kbd>W</kbd> | Left Click | Tap Screen or **FLAP** button |
| **Spit Fireball** | <kbd>F</kbd> / <kbd>X</kbd> / <kbd>Enter</kbd> | Right Click | Tap **FIRE** button |
| **Toggle Audio** | Click 🔊 button | Click 🔊 button | Tap 🔊 button |

## 🌟 Key Features

1. **Pluffy The Fire Bird**:
   - Cute chubby aesthetic with expressive blinking eyes and animated flapping wings.
   - Dynamic trailing flame physics emitting sparks, embers, and smoke puffs.
   - Snappy upward flaps with tilt rotation physics.

2. **Fiery Combat & Destruction**:
   - **Fireball Cannon**: Shoot burning fireballs at volcanic basalt pillars to shatter them into smoking debris and earn bonus points.
   - **Super Inferno Mode**: Collect 3 glowing Fire Orbs to transform Pluffy into a golden phoenix for 6 seconds—invincible against obstacles and smashing directly through pillars!
   - **Combo Multipliers**: Blast obstacles in quick succession to trigger combo multipliers (`x2`, `x3`, `x4`) and boost your score.

3. **Infernal Visual Atmosphere**:
   - Animated volcanic backdrop with glowing blood-red moon and silhouettes.
   - Undulating boiling magma lava floor with glowing heat crust.
   - Screen shake impacts on explosions, crashes, and power-up transformations.
   - Additive-blended particle engine delivering hundreds of embers, smoke plumes, and explosion rings at 60 FPS.

4. **Procedural Sound Engine**:
   - Built entirely with Web Audio API (100% self-contained—zero external audio files or network requests required).
   - Dynamic flap whoosh, fireball launch blasts, explosion rumbles, power-up arpeggios, and an ambient volcanic synth-bass soundtrack.

5. **Persistence & Polish**:
   - High scores saved automatically in browser `localStorage`.
   - Medals awarded based on performance (Embers, Wildfire, True Blaze, Phoenix Lord).
   - Fully responsive design scaling cleanly on mobile phones, tablets, and desktop displays.
